# 🟢 Tic-Tac-Toe React App

A **dark-themed Tic-Tac-Toe** game built with **React (JSX only)**.  
Enjoy classic X vs O gameplay with a modern dark UI and glowing winning effect.


## Demo

Tic-Tac-Toe game board showing a tied game with X and O marks arranged in a 3x3 grid on a dark background. The board displays X in top-left and top-center, O in top-right; O in middle-left and center, X in middle-right; and X in bottom-left and bottom-center, O in bottom-right. A teal-bordered Reset button is visible below the board with Tie! text displayed. 

## Features

- Track current player’s turn
- Automatically detect the winner
- Highlight winning combination with teal glow
- Detect tie games
- Reset game button
- Responsive and clean design

## Technologies Used

- **React**
- **JavaScript**
- **CSS3**
